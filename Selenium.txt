1.waits -> Implicit , explicit and fluent wait\
 1. Implicit Wait

     Applied globally
     Waits for elements to appear
  e.g. driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));

2.Explicit Wait
   Waits for a specific condition
e.g. WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
    wait.until(ExpectedConditions.visibilityOfElementLocated(locator));

3.Fluent wait 
     Advanced explicit wait with polling interval

  e.g. Wait<WebDriver> wait = new FluentWait<>(driver)
      .withTimeout(Duration.ofSeconds(20))
      .pollingEvery(Duration.ofSeconds(5))
      .ignoring(NoSuchElementException.class);

Screenshots in selenium ->

In my Selenium framework, I use the TakesScreenshot interface to capture screenshots. I have implemented screenshot capture inside TestNG listeners so that whenever a test case fails, a screenshot is automatically taken and attached to Extent Reports for debugging and defect analysis. This helps identify the exact UI state at the moment of failure."

import org.apache.commons.io.FileUtils; // For easy file operations

public class ScreenshotExample {

    public static void main(String[] args) {
        // Set the path to your ChromeDriver executable
        System.setProperty("webdriver.chrome.driver", "path/to/chromedriver");

        // Initialize WebDriver
        WebDriver driver = new ChromeDriver();

        try {
            // Navigate to a website
            driver.get("https://www.example.com");

            // Convert WebDriver object to TakesScreenshot
            TakesScreenshot ts = (TakesScreenshot) driver;

            // Capture the screenshot as a File
            File sourceFile = ts.getScreenshotAs(OutputType.FILE);

            // Define the destination for the screenshot
            File destinationFile = new File("./screenshots/screenshot.png");

            // Copy the source file to the destination
            FileUtils.copyFile(sourceFile, destinationFile);

            System.out.println("Screenshot taken and saved to: " + destinationFile.getAbsolutePath());

        } catch (IOException e) {
            System.err.println("Failed to capture screenshot: " + e.getMessage());
        } finally {
            // Close the browser
            driver.quit();
        }
    }
}
Taking a screenshot (or "snap") in Selenium with Java involves using the TakesScreenshot interface and its getScreenshotAs() method. This allows you to capture the visible portion of the browser window.

6. How do you handle multiple windows in Selenium?
✔️ Answer:
I handle multiple windows using getWindowHandle() and getWindowHandles(). I first store the parent window ID, perform the action that opens the new window, then iterate through all window handles and switch to the required child window using driver.switchTo().window(). After completing the required actions, I close the child window and switch back to the parent window.  



String parent = driver.getWindowHandle();
Set<String> allwindows = driver.getWindowHandles();

for (String child : allwindows) {
    if (!child.equals(parent)) {
        driver.switchTo().window(child);
    }
}

10. How doo you take snaps in selenium?

File src = ((TakesScreenshot)driver).getScreenshotAs(OutputType.FILE);
FileUtils.copyFile(src, new File("screenshot.png"));

File src = ((TakesScreenshot)driver).getScreenshotAs(OutputType.FILE); ->
driver is your Selenium WebDriver instance.
(TakesScreenshot) driver casts your WebDriver to this screenshot-capable interface.
.getScreenshotAs(OutputType.FILE) takes a screenshot and returns it as a File object.
The screenshot taken by the driver is stored in a temporary file, and this reference is kept in the variable src.
So this line captures a screenshot of the current browser window and stores it in a temporary file.

FileUtils.copyFile(src, new File("screenshot.png")); ->
FileUtils is from Apache Commons IO.
.copyFile(src, new File("screenshot.png")) copies the temporary screenshot file (src) into a new file named screenshot.png in your project or working directory.
So this line saves the screenshot permanently to a file called screenshot.png.

17.1️⃣ Encapsulation — Hiding data using classes + private variables

Bind data + methods inside a class.

Access using getters/setters.

Example:

public class LoginPage {
    private String username;
    public void setUsername(String user) { this.username = user; }
}
18.2️⃣ Inheritance — Child acquires properties of parent

Example:

class BasePage { WebDriver driver; }
class LoginPage extends BasePage { }

3️⃣ Polymorphism — One name, multiple forms

Method overloading (compile-time)

Method overriding (runtime)

Example:

public void click(String locator);
public void click(WebElement element);

4️⃣ Abstraction — Showing functionality, hiding complexity

Achieved via abstract class/interface.

Example:

interface DriverActions { void click(); }
