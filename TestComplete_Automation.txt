4.What is checkpoint in testcomplete ?
->A checkpoint in TestComplete is an automated verification command that compares the actual state of your application against an expected baseline during test execution
Just E.G.->
function TestPropertyCheckpoint() {
  // Access the target object using Aliases
  let page = Aliases.Browser.PageMain;
  let welcomeLabel = page.PanelWelcome;
  
  // Verify that the 'contentText' property equals "Welcome, User!"
  // Syntax: aqObject.CheckProperty(Object, PropertyName, Condition, ExpectedValue)
  aqObject.CheckProperty(welcomeLabel, "contentText", cmpEqual, "Welcome, User!");
}
